# PairLink Final
Upload `index.html` to the root of the GitHub Pages repository.
Open the site, copy the generated link, and send the exact link to the other person.
Status:
🟡 Waiting = nobody connected
🟢 Connected = other person connected
🔴 Disconnected = connection lost/offline

No database or chat history is used. PeerJS is used for WebRTC signaling/connection setup.
